Connect your accounts

Paste the credentials you get from each platform's own developer portal. They're saved locally on this server, never committed to the repo, and only ever used server-side. Leave a field blank to keep whatever's already saved.

Growth goal

Set a total-follower target across all channels. The public dashboard shows progress and a projected date, computed from the same 7-day trend as everything else — a straight-line estimate, not a forecast.

Content queue

Plan drafts against the best-time-to-post slots. This is a planning list only — nothing here posts automatically. Actually publishing would need write-scoped OAuth and app review from each platform, which this dashboard doesn't request.

Competitors

Track up to 5 public accounts to benchmark your growth against on the dashboard's Versus chart. Public follower counts only, read through the official APIs with your own keys — YouTube (any channel ID) and X (any public username) are the two platforms where this works at basic API tiers.

Notifications

With NOTIFY_WEBHOOK_URL set in the server environment (a Discord or Slack incoming-webhook URL — it's a secret, so it stays in env, never in the database), Signal sends a weekly digest and one-time milestone alerts (10K, 25K, 50K, 100K, 250K, 500K, 1M followers per platform).
